Tải bot cho máy tính (ZIP)

Cài đặt (Chrome trên máy tính)

  1. Giải nén file ZIP vừa tải.
  2. Mở chrome://extensions, bật Developer mode.
  3. Bấm Load unpacked, chọn thư mục vừa giải nén.
  4. Mở pokesurvivor.com hoặc pokesurvivor.doofcraft.com, nhập số ván rồi bấm ▶ Chạy.

Cài đặt (điện thoại Android)

ℹ️ pokesurvivor.com chặn script chèn vào trang (CSP), nên trên Android phải dùng Firefox: bot chạy bằng quyền của userscript, không cần chèn script. Kiwi / Chrome trên Android không chạy được với bản thường; pokesurvivor.doofcraft.com vẫn chạy bình thường trên mọi trình duyệt.

  1. Cài Firefox (CH Play).
  2. Trong Firefox, cài tiện ích Violentmonkey hoặc Tampermonkey (menu ⋮ → Tiện ích).
  3. Bấm Copy, dán vào thanh địa chỉ của trình duyệt đó rồi mở:
    https://raw.githubusercontent.com/damhieu2808/PokeSurvivorTool/release/psbot.user.js
  4. Tampermonkey tự mở trang cài script → bấm Install (Cài đặt).
  5. Vào game. Lần đầu, Tampermonkey hỏi quyền truy cập raw.githubusercontent.com (nơi bot tải code): chọn Always allow (luôn cho phép) rồi tải lại trang. Không cho phép thì bot không chạy.
  6. Panel PokeSurvivor Bot hiện ở góc trên bên trái. Bot tự cập nhật, không cần cài lại.

Cài đặt (iPhone / iPad)

  1. Cài app Userscripts (App Store, miễn phí).
  2. Mở Cài đặt → Safari → Tiện ích → Userscripts: bật lên và cho phép trên mọi trang web.
  3. Bấm Copy ở phần Android phía trên, dán vào thanh địa chỉ của Safari rồi mở.
  4. Bấm biểu tượng tiện ích (hình mảnh ghép hoặc aA) trên thanh địa chỉ → Userscripts → Cài đặt (Install).
  5. Vào game trong Safari: panel hiện ở góc trên bên trái. iOS chưa thử; pokesurvivor.com có thể bị chặn như trên Android. Nếu lỗi, báo qua liên hệ bên dưới.

Download the bot for PC (ZIP)

Install (Chrome on PC)

  1. Unzip the downloaded file.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Open pokesurvivor.com or pokesurvivor.doofcraft.com, enter the number of runs and press ▶ Chạy (Run).

The bot's panel is in Vietnamese: ▶ Chạy = Run, ■ Dừng = Stop, Số ván = number of runs (0 = forever), ⚔ Moveset = pick the 4 moves the bot prefers. Keys: F8 toggles the bot, F9 shows what it sees.

Install (Android phone)

ℹ️ pokesurvivor.com blocks scripts added to the page (CSP), so on Android use Firefox: the bot runs with the userscript manager's privileges and never adds a script. Kiwi / Chrome on Android cannot run the normal version; pokesurvivor.doofcraft.com still works in any browser.

  1. Install Firefox (Play Store).
  2. In Firefox, install the Violentmonkey or Tampermonkey add-on (menu ⋮ → Add-ons).
  3. Tap Copy, paste into that browser's address bar and open it:
    https://raw.githubusercontent.com/damhieu2808/PokeSurvivorTool/release/psbot.user.js
  4. Tampermonkey opens its install page → tap Install.
  5. Open the game. The first time, Tampermonkey asks for access to raw.githubusercontent.com (where the bot downloads its code): choose Always allow, then reload the page. Without it the bot can't run.
  6. The PokeSurvivor Bot panel appears in the top-left corner. The bot updates itself, no reinstall needed.

Install (iPhone / iPad)

  1. Install the Userscripts app (App Store, free).
  2. Open Settings → Safari → Extensions → Userscripts: turn it on and allow it on all websites.
  3. Tap Copy in the Android section above, paste into Safari's address bar and open it.
  4. Tap the extensions icon (puzzle piece or aA) in the address bar → Userscripts → Install.
  5. Open the game in Safari: the panel appears in the top-left corner. iOS is untested; pokesurvivor.com may be blocked as on Android. If something goes wrong, use the contact below.
