# PokeSurvivor Bot

Bot tự chơi [pokesurvivor.com](https://pokesurvivor.com) và [pokesurvivor.doofcraft.com](https://pokesurvivor.doofcraft.com/#play) (tự nhận bản game theo trang). Miễn phí · tác giả [damhieu2808](https://github.com/damhieu2808)

**Cài (Chrome trên máy tính):** [tải ZIP](https://github.com/damhieu2808/PokeSurvivorTool/archive/refs/heads/release.zip), giải nén, mở `chrome://extensions`, bật Developer mode, bấm Load unpacked và chọn thư mục vừa giải nén.

**Điện thoại:** cài app Userscripts (iOS) hoặc Tampermonkey, rồi mở [psbot.user.js](https://raw.githubusercontent.com/damhieu2808/PokeSurvivorTool/release/psbot.user.js) để cài.

**Dùng:** vào game, nhập **Số ván** (0 = chơi mãi) rồi bấm **▶ Chạy**, bấm lại để **■ Dừng**. **⚔ Moveset** để chọn 4 move bot ưu tiên cho từng pokémon. Phím tắt: **F8** bật/tắt bot, **F9** hiện lớp vẽ (bot đang thấy gì).

**Cập nhật:** khi panel hiện dòng vàng "⬆ Có bản mới", tải lại ZIP rồi giải nén đè lên thư mục cũ. Bản cài trên điện thoại tự cập nhật.
